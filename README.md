# Blog

My blog site where I publish articles on topics that interest me. Built using a slightly modified version of the Fuwari template.

How do you run this:
1. pnpm install (to install dependencies)
2. pnpm dev (run dev server)
3. pnpm build (creates the production build to the dist folder)

To add images to blog posts, use the following markdown syntax:
`![Moonlight View](src/assets/images/Remote_Streaming/image.png "The client window on my Mac")`
